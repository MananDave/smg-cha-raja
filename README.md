## 🎵 Background Music

Add your music file and name it exactly:

`bg-song.mp3`

Keep it in the same folder as `index.html`. Music starts when the visitor presses the opening invitation button.

## 🖼️ Opening Background

The opening screen currently uses `opening-bg.jpg`. A copy of the existing Ganpati photo is included as the default.

You can replace it with your preferred photo later, keeping the exact filename:

`opening-bg.jpg`

The opening background is responsive for mobile and desktop and uses a cinematic dark/blurred treatment.
